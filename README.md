# Attack On Agent

Attack On Agent — defensive-security PoC для проверки AI-агентов с долговременной памятью и инструментами.

## Проблема

Агент может получить вредную инструкцию, сохранить её в памяти и использовать позднее — в другой сессии или при вызове инструмента. Обычная проверка одного ответа не показывает такую цепочку и не доказывает её последствия.

## Решение

Проект проводит контролируемые атаки на тестовом стенде и показывает, привели ли они к:

- вредному ответу;
- изменению долговременной памяти;
- небезопасному действию через инструмент.

## MVP

Первый сценарий воспроизводит полный путь: атака попадает в память, переживает завершение сессии, активируется позднее и приводит к наблюдаемому результату.

Все эксперименты выполняются на контролируемом стенде с синтетическими данными.
